# Farhan Kabir — Personal Portfolio

A single-page portfolio website built with Next.js and Tailwind CSS. Deploy-ready on Vercel.

## Setup

```bash
npm install
npm run dev
```

## Add Your Photo

Place your profile photo at `public/photo.jpg` for the About section. If missing, initials "FK" will be shown.

## Deploy on Vercel

Connect this repo to [Vercel](https://vercel.com) for one-click deployment.
